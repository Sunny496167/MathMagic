# MathMagic & MathLearn Platform 🌟

A complete interactive math learning ecosystem consisting of a **React Native Expo** mobile app (`MathMagic/`) and a **Node.js Express** backend API (`backend/`).

---

## 📂 Repository Structure

- **[`MathMagic/`](./MathMagic/README.md)**: React Native mobile application powered by Expo SDK 52, Expo Router, NativeWind (Tailwind CSS), and TanStack Query.
- **[`backend/`](./backend/README.md)**: Mobile-first REST API built with Node.js, Express.js, MongoDB (Mongoose), Redis, and JWT Access + Refresh token rotation.

---

## ⚡ Quick Start Guide

### 1. Start the Backend API

```bash
cd backend
npm install
npm run dev
```

*Backend runs on `http://0.0.0.0:5000`.*

### 2. Start the Mobile Application

```bash
cd MathMagic
npm install
npx expo start
```

*Open in Expo Go, Android Emulator (`a`), or iOS Simulator (`i`).*
