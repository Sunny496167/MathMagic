You are a senior frontend developer, UI/UX designer, educational product designer, and learning-system architect.

Build a complete Grade 1 Mathematics learning experience inside a modern math-learning platform called "MathLearn".

The goal is NOT to create a simple school syllabus page. Build a complete interactive learning system where a Grade 1 learner can learn concepts, practice hundreds of questions, play math games, take quizzes, review mistakes, track progress, and gradually achieve mastery.

The application should feel modern, friendly, motivating, and premium. It should be suitable for children around Grade 1 while still looking professional and not like a cheap children's game.

TECH STACK:
- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- Component-based architecture
- Responsive/mobile-first design
- Reusable components
- Local/mock data initially, but structure the application so a backend/API can easily be connected later.
